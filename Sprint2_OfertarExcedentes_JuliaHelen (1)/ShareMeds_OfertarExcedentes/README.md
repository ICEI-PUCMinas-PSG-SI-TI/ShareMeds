# ShareMeds - Ofertar excedente (CRUD)

1. Instale o Node.js e depois: `npm install -g json-server@0.17.4`
2. Na pasta do projeto: `json-server --watch db.json` (API em http://localhost:3000/ofertarExcedente)
3. Abra o `ofertar-excedentes.html` no navegador (ou use a extensão Live Server do VS Code).

Operações implementadas (API REST do JSONServer):
- CREATE: formulário "Ofertar excedente" -> POST
- READ: tabela "Ofertas cadastradas" -> GET
- UPDATE: botão "Editar" na tabela, depois "Salvar alterações" -> PUT
- DELETE: botão "Excluir" na tabela -> DELETE
