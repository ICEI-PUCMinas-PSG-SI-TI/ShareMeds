# ShareMeds - Meus pedidos (Sprint 1)

Tela "Meus pedidos" (Wireframe 10), com cabeçalho azul, botão "← Início" e cartões com medicamento, hospital e status.

1. Instale o Node.js e depois: `npm install -g json-server@0.17.4`
2. Na pasta do projeto: `json-server --watch meus-pedidos-db.json` (API em http://localhost:3000/pedidos)
3. Abra o `meus-pedidos.html` no navegador (ou use a extensão Live Server do VS Code).

O botão "← Início" ainda não tem funcionalidade; será integrado à tela inicial na Sprint 3.
